Project: 
Task Manager Web Application

Context: 
The app is centered around projects and tasks. Users can create projects, open a project workspace, add tasks, track progress, and view task data in list, calendar, and analytics views.

Tech Stack 
Frontend: React, TailwindCSS
Backend: Node.js, Express.js
Database: MongoDB, Mongoose ORM

Features:
- Dashboard with project and task summary cards
- Create and view projects
- Project-specific task workspace
- Create tasks with status, priority, type, and due date
- Task list view
- Calendar view for upcoming task deadlines
- Analytics view with status and priority charts
- Project settings page for updating project details
- REST API for projects and tasks

Goals:
Migrate this project's backend database from MongoDB to Mysql.

Requirements:
- Replace MongoDB with MySQL
- Replace Mongoose ORM models with MySQL-compatible models
- Create appropriate MySQL table schemas
- Add relationships between projects and tasks
- Update database queries accordingly
- Preserve all existing API endpoints
- Preserve all logic

Constraints:
- Don't change the core functionality of the project.
- Do not add anything extra in the project.
- Do not change API Routes
- Do not change UI
